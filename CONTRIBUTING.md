# Collaboration guidelines

This library is under active development. Until it is feature-complete, we want to keep close control over its API, architecture, and implementation. **We are therefore not accepting pull requests at this stage.**

We are building an **improved and extended version of EPANET**, rather than a one-to-one rewrite of the original C codebase. Existing behavior and implementation choices inform our work, but we may deliberately revisit them to improve the design, functionality, and maintainability of the library.

Ideas, suggestions, and bug reports are welcome. If you would like something changed, **please open an issue first** so we can discuss the problem, proposed behavior, and how it fits into the library. This includes changes to the public API, architecture, dependencies, and existing code.

**We do not accept AI-generated code contributions.** Generating more code is not our bottleneck; deciding what belongs in the library and taking responsibility for its design and maintenance is. If we choose to use AI during development, we will do so ourselves under our own review.

The most useful contribution right now is a clear issue: explain your use case, describe the limitation or bug, and include a small reproducible example where relevant.

We may revisit this policy as the library matures.
